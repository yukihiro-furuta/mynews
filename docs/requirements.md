# MyNews 要件定義書

**作成日:** 2026-11-01  
**作成者:** yukihiro furuta  
**バージョン:** 1.0

---

## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| アプリ名 | MyNews |
| 種別 | Progressive Web App (PWA) |
| 目的 | 特定ジャンルのニュースを毎日快適にチェックする自分専用アプリ |
| 対象ユーザー | 自分（個人利用） |
| 対応端末 | iPhone（主）、PC（副） |
| 公開先 | Vercel（プライベート利用） |

---

## 2. 機能要件

### 2-1. ニュース取得・表示 ✅ 実装済み

| # | 機能 | 説明 |
|---|---|---|
| F01 | RSSフィード取得 | 7フィードを並列取得し、新着順に一覧表示 |
| F02 | カテゴリフィルター | すべて / 経済 / スタートアップ / 静岡 / 長野 / 農業 |
| F03 | 記事カード表示 | タイトル・メディア名・投稿時刻・カテゴリバッジを表示 |
| F04 | 外部リンク | 記事タップで元記事をブラウザで開く |

**対応フィード:**

| フィード | カテゴリ |
|---|---|
| NHK経済 | 💹 経済 |
| TechCrunch Japan | 🚀 スタートアップ |
| THE BRIDGE | 🚀 スタートアップ |
| NHK静岡 | 🗾 静岡 |
| NHK長野 | 🗾 長野 |
| マイナビ農業 | 🌾 農業 |
| JA新聞 | 🌾 農業 |

---

### 2-2. 記事保存 ✅ 実装済み

| # | 機能 | 説明 |
|---|---|---|
| F05 | 記事保存 | ⭐ボタンで記事をlocalStorageに保存 |
| F06 | 保存一覧 | `/saved` ページで保存記事を一覧表示 |
| F07 | 個別削除 | 保存済み記事を個別に削除 |
| F08 | 全削除 | 確認ダイアログ付きで全記事を一括削除 |

---

### 2-3. PWA化 🔜 次のステップ

| # | 機能 | 説明 |
|---|---|---|
| F09 | ホーム画面追加 | iPhoneのSafariからホーム画面に追加できる |
| F10 | スプラッシュ画面 | 起動時にアプリアイコンと名前を表示 |
| F11 | スタンドアロン表示 | ブラウザUIを非表示にしてアプリ風に表示 |
| F12 | オフライン対応 | キャッシュにより直前の記事をオフライン閲覧可能 |

---

### 2-4. プッシュ通知 ⬜ 未着手

| # | 機能 | 説明 |
|---|---|---|
| F13 | 朝の通知 | 毎朝7時に最新ニュース5件をプッシュ通知 |

## 3. 非機能要件

| 項目 | 要件 |
|---|---|
| レスポンシブ | スマートフォン（375px〜）からPCまで対応 |
| パフォーマンス | 初期表示3秒以内（RSS取得中はローディング表示） |
| 可用性 | Vercel無料プランで運用（月間帯域100GB以内） |
| セキュリティ | 個人利用のため認証不要。localStorageはユーザー端末のみに保存 |
| プライバシー | 外部APIへのデータ送信なし（RSSは読み取りのみ） |

## 5. 画面構成

```
/              ← ホーム（記事一覧 + フィルタータブ）
└ /saved    ← 保存済み記事一覧
```
